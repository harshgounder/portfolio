The problem

REA is an agent-first reverse-engineering tool with a fork network large enough that who is building on it is a real research question. The first pass found 66 forks and called it a landscape.

What I built

Six waves: understand the upstream from source, score the fork network, profile the competing agent-RE projects, harvest 688 specialised tools from 42 GitHub topics, read 292 papers out of a 1,084-paper harvest, then audit upstream drift. Every repo and paper ID cited by the research reports gets a live check in a TSV.

What proves it

Claims carry a source and a verified or unverified tag. Subagent output is a claim until a review table says otherwise. The build phase waits for an explicit GO, which is the honest state of the work.
